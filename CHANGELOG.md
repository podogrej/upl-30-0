# 30-0 УПЛ — журнал изменений

Технический журнал: что менялось по версиям, в каких файлах, что залить и что выполнить.
Как устроен проект — в [README](README.md). Правила, которые не меняем, — в [DECISIONS](DECISIONS.md). Идеи и задачи — в [BACKLOG](BACKLOG.md).
Для игроков то же самое коротко и по-украински показывается в игре: ссылка «Що нового» в подвале, константа `WHATSNEW` в `src/template.html`.

Версии 0.1–0.79.2 — в архиве [docs/archive/changelog_0.1-0.79.md](docs/archive/changelog_0.1-0.79.md), 0.80–0.84.1 — [docs/archive/changelog_0.80-0.84.md](docs/archive/changelog_0.80-0.84.md).

## Как вести журнал

- Новая запись идёт сверху при каждом выпуске, если меняется номер в подвале («Що нового у версії X.YY» в `src/template.html`).
- Разделы записи: **Игра**, **Данные**, **Сервер**, **SQL**, **Залить**. Пустые разделы пропускаются.
- Номер версии в подвале и `VERSION` в `lib/engine.js` должны совпадать: сервер проверяет сезон только той версией движка, которой он сыгран. Поэтому `index.html` и `lib/engine.js` всегда заливаются вместе.
- При каждом выпуске обновляется `WHATSNEW` — это текст для игроков о последней версии.

## 0.90.1 «Античит одним выпуском» — 13.10.2026

Весь остаток серии `docs/anticheat_090.md` (0.90.1–0.90.3) одним выпуском по решению владельца 13.10. Защита сайта (CSP) остаётся в режиме отчётов: сбор отчётов на проде не работал, см. ниже.

**Игра**
- Колесо обычной игры, лиги с друзьями и вызова другу выдаёт сервер (`/api/seed {draft:'start'}` → `ws`), колесо в браузере — `wheelFor(ws, формат, эпоха, клуб)` (для классики/всех лет побитово равно старому `wheelSeq`, 299/299). Без ответа за 6 с, при дневном лимите и в скрытых форматах — локальное колесо, сезон не проверяется, строка под результатом.
- «Грати сезон» фиксирует состав на сервере (`draft:'lock'`): сервер проверяет состав по колесу, считает сезон и отдаёт seed.
- Вызов другу создаётся только из своего проверенного сезона с серверным колесом; результат вызова пишет сервер при фиксации состава.
- Своё имя — после первого проверенного сезона (автоимя из Telegram/Google не затронуто).

**Сервер**
- `api/_draft.js`: старт (только «Звичайний», «Складний», «Тренування» в классике и «Одному клубі»; правила лиги и вызова — из базы; 60 стартов на игрока в сутки) и фиксация (окно колеса по формату/эпохе из `tools/wheel_window.js`, не больше `rerolls` игроков вне колеса, один игрок на остановку колеса; сезон считается на сервере, `res`, `locked_at`). Повтор с тем же составом — тот же ответ, другой состав — 409. Попытка лиги с друзьями тратится при фиксации (`fl_record_seed`), брошенный сезон тоже.
- `api/seed.js`: старый путь без `draft` выдаёт seed `kind='legacy'` и не отмечает попытку лиги чата; такие сезоны — `verified=null`.
- `api/verify.js`: проверен только сезон с зафиксированным серверным колесом (кроме «Драфту дня» и «Виклику дня»), эпоха/лига/клуб/тренування сверяются с колесом; `PREV_VERSIONS` = 0.90, 0.89.1, 0.89.
- Трофеи сезона и вехи «N сезонів» пишет сервер из проверенного сезона (`trophies.src='srv'`), условия те же (`TROPHIES` из сайта в `lib/engine.js`), xP сервер считает сам (`xpOf`, те же 300 прогонов, ~0,2 с; тест `xp_parity.js`: побитово равно сайту). Заявки браузера на трофеи сезона и вехи отбрасываются.
- Попытка лиги чата тратится при фиксации состава, порядок попыток — по времени фиксации (`dayBest`). Фиксация повторяется до 2 раз при обрыве или 5xx (повтор безопасен). Вызов без связи с сервером всё равно идёт по колесу вызова; уровень вызова — «Складний» или «Звичайний» одинаково в браузере и на сервере.
- `tools/make_engine.js` собирает движок из готового `index.html` (трофеи и рекорды клубов уже вставлены).
- `/api/err?csp=1`: тело отчёта читается из потока — Vercel не разбирает `application/csp-report`, поэтому с 0.90 в базу не попал ни один отчёт (проверено 13.10: браузер на проде отчёт отправляет, в `client_errors` пусто).

**SQL** `sql/v0901_anticheat.sql`: поля `season_seeds` (`kind`, `wheel_seed`, `era`, `club`, `rerolls`, `fl_id`, `chal_id`, `locked_at`, `res`), `fl_entries.seed_id` и `season_id` без `not null`, `fl_record_seed`, `fl_record` связывает попытку с сезоном, `trophies.src`, имя после первого сезона, лимит по IP в `player_hello`/`set_player_name`/`set_player_auto_name`, кэш `game_stats`/`trophy_stats` на 10 минут (`stats_cache`).

**Тесты**: `tools/wheel_window.js` (окно колеса), `xp_parity.js`; `cheat.js`, `chal.js`, `v078.js`, `v079.js`, `v39.js`, `tro.js`, `draft58.js` под новый порядок.
