# «Клас» гравця — данные для рейтингов v2

Что это: для каждой «человеко-карточки» (id `p[5]` в `src/pool.json`) — факты о карьере вне сезонной статистики УПЛ:
сборная, еврокубки, рыночная стоимость и трансферы на Transfermarkt, награды. Нужно для формулы рейтингов v2
(`docs/ratings_v2.md`: 90+ — только у 10–20 человек за всю историю). В игре ничего не меняет.

## Файлы

| Файл | Что |
|---|---|
| `collect.py` | сборщик (идемпотентный, с кэшем, `CACHE_ONLY=1` — перестроить CSV без сети) |
| `class.csv` | данные с источниками, одна строка на человека |
| `proposal.py` | анализ: оценка класса и 3 варианта смешивания с сезонным рейтингом |
| `class_score.csv` | класс C (0…1) и его составляющие по людям (выход `proposal.py`) |
| `proposal.md` | предложение для владельца: таблица «было → стало», варианты A/B/C |

Запуск из корня репозитория:
```
python3 data/class/collect.py <папка кэша> [минут_бюджета=300]
CACHE_ONLY=1 python3 data/class/collect.py <папка кэша>
python3 data/class/proposal.py --md
```

## Кандидаты и покрытие (30.09.2026)

- Кандидаты: 740 человек — все, у кого есть карточка ≥ 84 (736), плюс 5+ сезонов в «Динамо»/«Шахтаре» (133; пересечение большое).
- Transfermarkt ID найден и подтверждён у **710 из 740** (96%):
  406 — id `tm:N` напрямую; 103 — уже проверенные ссылки в `data/foot`, `data/positions`; 169 — Wikidata P2446 + та же дата рождения;
  32 — поиск на transfermarkt.com + та же дата рождения. Для всех `w:`-id дата рождения на TM совпадает с нашей, фамилия латиницей похожа ≥ 0.7.
- Не найдено 30 человек (все из 1990-х или с неточным id; самый высокий рейтинг — Флорін Чернат 90, Юрій Букель 89, Шматоваленко 89, Джіхані 89).
  Их класс сейчас = 0 (в варианте A/B/C их лучшие карточки опустятся до 84–88) — их стоит добить вручную перед выпуском.
- По 710 найденным данные собраны полностью (сборная, все матчи, трансферы). Сборная > 0 матчей — 385; еврокубки > 0 — 636;
  пиковая стоимость — 552; сумма трансфера — 319; награды — 75 человек.

## Колонки `class.csv`

`person_id, name, max_rating, best_card, cards84, dk_sh_seasons` — из пула;
`tm_id, tm_name, dob` — профиль TM;
`caps, intl_goals, country, ukraine, other_senior, youth_caps` — основные сборные (сумма по всем взрослым сборным: СССР/СНГ + Украина и т. п.),
молодёжные U17–U23/олимпийские/«B» отдельно в `youth_caps`;
`euro_apps, ucl_apps, euro_goals, euro_apps_foreign` — сыгранные матчи в клубных еврокубках (ЛЧ с квалификацией, Кубок УЕФА/ЛЕ, ЛК, Кубок кубков, Интертото, Суперкубок), `ucl_apps` — только основной турнир ЛЧ;
`peak_mv_eur, peak_mv_date` — максимальная рыночная стоимость TM; `max_fee_eur, max_fee_move` — самый дорогой трансфер (не аренда), `max_loan_fee_eur` — платная аренда;
`awards` — список через «;»: `UF #N год` (опрос газеты «Український футбол», топ-3, 1991–2024), `Komanda #N год` (премия «Команды», топ-3 1995–2016), `Komanda1 #N год` (2017–2020), `UPL top scorer сезон`, `Ballon d'Or #N год` (места 1–30; 2010–2015 — FIFA Ballon d'Or, до 23-го места), `UEFA Team of the Year год` (опрос болельщиков UEFA.com 2001–2020);
`sources` — все URL, откуда взяты числа; `checked` — дата; `note` — как найден TM id и оговорки.

## Источники

- `tmapi.transfermarkt.technology` — внутренний API самого сайта Transfermarkt: `/players` (дата рождения, пик стоимости),
  `/player/<id>/national-career-history` (матчи/голы за каждую сборную), `/player/<id>/performance-game` (все матчи игрока в базе TM),
  `/transfer/history/player/<id>` (трансферы), `/clubs` (названия клубов и сборных). Он не закрыт «Human Verification», пауза 1,5 с.
- `www.transfermarkt.com` — только поиск по фамилии для 60 ненайденных (пауза ≥ 6 с, при блокировке 90 с).
- Wikidata (SPARQL): дата рождения → TM id; название статьи → TM id (для наград).
- Английская Википедия (`action=raw`): «Ukrainian Footballer of the Year», шаблон «Ukrainian Premier League top scorers»,
  «<год> Ballon d'Or», «UEFA Team of the Year». Награда засчитывается, если у статьи в Wikidata тот же TM id, что у нашего человека;
  если у статьи нет TM id (или это перенаправление) — только однозначное совпадение полного имени ≥ 0.9 (помечено в `note`).

## Оговорки по качеству

- **Стоимость в 1990-х.** Рыночные стоимости на TM есть примерно с 2004 года. У ветеранов 90-х (Лужний, Головко, Леоненко, Калитвинцев)
  в `peak_mv_eur` — стоимость конца карьеры или пусто. Трансферные суммы 90-х есть частично (Ребров → «Тоттенхэм» €18 млн есть,
  у многих — «?»). В `proposal.py` для родившихся ≤ 1977 «деньги» могут только повысить класс, но не понизить.
- **Еврокубки в 1990-х** на TM покрыты неполно (особенно квалификация и Кубок кубков начала 90-х) — у старых игроков `euro_apps`
  скорее занижено. Колонка `note` показывает, с какого года в базе TM есть их еврокубковые матчи.
- **Сборная.** Берётся из TM (`national-career-history`), не из Wikidata. СССР/СНГ считаются взрослой сборной.
  Шацьких — Узбекистан, Срна — Хорватия и т. д.: страна не важна, считается только уровень.
- **Награды.** Шаблон бомбардиров в англ. Википедии содержит ошибку (два «2022–23») — взято как есть, на класс почти не влияет.
  «Українский футбол» — это опрос только среди украинцев; «Команда» — среди игроков УПЛ любой страны. Золотой мяч матчится
  лишь у Шевченко (6 раз в топ-30) и Довбика (2024). В 2021 и 2025 у «Украинского футбола» нет данных.
- **UEFA Team of the Year** — это опрос болельщиков, а не экспертная сборная; вес в `proposal.py` небольшой.
- `euro_apps_foreign` — грубая оценка (матчи не за украинские клубы по названию клуба).
