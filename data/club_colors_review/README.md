# Цвета клубов — проверка low/medium (30.09.2026)

Проверены все 38 клубов с `confidence` low/medium из `data/club_colors.csv`. **Сам `club_colors.csv` не менялся.**
Предложение — `club_colors_proposed.csv`: те же колонки + `source` (откуда) + `note` (что и почему), все 51 строка
(high-строки не проверялись и оставлены как есть, `note` = «не перевірялось (high)»). Чтобы применить — скопировать колонки
`code,name,c1,c2,c3,confidence` поверх `data/club_colors.csv` и пересобрать (`python3 src/build.py && node tools/make_engine.js`).

Напоминание: `c1` — заливка фишки, `c2` — обводка, `c3` — запасной цвет текста (игра берёт `c2`/`c3`, если контраст с `c1` ≥ 3,2,
иначе белый/чёрный).

## Источники

- uk/en-вики: параметры формы в инфобоксе (`body1/shorts1`, `футболка1/труси1` — основная, `…2` — выездная), текст статьи
  («Кольори клубу — …», прозвища «жовто-чорні», «зелено-білі», «синьо-золоті»), ru-вики для «Олімпіка».
- Эмблемы клубов из статей uk-вики: скачаны и разобраны на доминирующие цвета (для «Маріуполя», «Іллічівця» и «Прикарпаття» — просмотрены глазами).
- Wikidata (P6364 «официальный цвет») у этих клубов пустая — не пригодилась. Сайты клубов не понадобились.
- Инфобокс показывает **последнюю** форму. Для исчезнувших клубов и клубов, у которых цвета менялись, брал цвета **лет в УПЛ**
  (эмблема того времени), а не нынешние.
