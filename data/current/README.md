# Текущий сезон УПЛ 2026/27: матчи игроков по клубам
Источник: Transfermarkt, страницы `leistungsdaten` каждого клуба (фильтр UKR1, saison_id=2026), собрано 2026-10-09 скриптом `collect_current.py <кэш>` -> `apps_2026.csv` (club_slug, player_id, tm_id, name, apps; только apps ≥ 1). Slug клубов — по `data/matches/club_names_map.csv` (в 2026 TM-клуб «FC Kharkiv» = fc-kharkiv, а в пуле до 2025 тот же клуб — `metalist-1925`).
Покрытие: 16 клубов, 369 игроков; 316 сопоставлено с пулом (`tm:<id>`, ID игрока TM совпал), 53 — новые игроки без истории в пуле; `w:`-игроки по имени и году рождения не нашлись ни разу. Из сопоставленных 101 играет за клуб, которого в пуле у него не было (из них 15 — Харків/Металіст 1925 из-за переименования).

## Заявки клубов: squads_2026.csv
Источник: Transfermarkt, страницы `kader` (saison_id=2026, `plus/1`), собрано 2026-10-09 скриптом `collect_squads.py <кэш>` -> `squads_2026.csv` (club_slug, player_id, tm_id, name; все числящиеся в заявке, даже без матчей). Покрытие: 16 клубов, 399 игроков, 333 сопоставлено с пулом (`tm:<id>`); slug клубов как в `apps_2026.csv` (fc-kharkiv оставлен как есть).
Заявки обновляются дважды в сезон: после закрытия летнего и зимнего трансферных окон.
