# Пасхалки по позициям: вратари в поле и защитники в нападении

Что это: поиск людей из пула (`src/pool.json`), которые в реальных матчах играли далеко не на своей позиции:
1) вратари, выходившие полевыми (в том числе в нападение); 2) защитники (CB/RB/LB), которых ставили
центрфорвардом или вторым нападающим. Попутно собрано: вратари, забивавшие голы, и защитники, стоявшие в воротах.
В игре ничего не меняет — это сырьё для трофеев/пасхалок. Сбор 01.10.2026.

## Файлы

| Файл | Что |
|---|---|
| `collect.py` | сборщик (идемпотентный, с кэшем; `CACHE_ONLY=1` — пересобрать CSV без сети) |
| `candidates.csv` | один матч — одна строка (колонки из задачи) |
| `summary.csv` | свод: человек × категория, сколько официальных матчей, минут, голов, проверка личности, профиль TM |
| `cache/<tm_id>.json` | сжатый список сыгранных матчей человека из TM; `cache/_stats.json` — итоги прогона |

Запуск из корня репозитория: `python3 data/easter_positions/collect.py [минут_бюджета]`,
`CACHE_ONLY=1 python3 data/easter_positions/collect.py`.

## Метод

- Источник: `tmapi.transfermarkt.technology/player/<id>/performance-game` (внутренний API Transfermarkt, как в
  `data/penalties`). В каждом матче есть `positionId` — позиция в этом матче по TM:
  1 GK, 3 CB, 4 LB, 5 RB, 6 DM … 13 второй нападающий, 14 центрфорвард; 0/пусто — неизвестно. Пауза 1,5 с.
- Кого проверяли: все люди пула, у которых основная позиция (по матчам в карточках) GK, CB, RB или LB:
  с id `tm:` — напрямую; с id `w:` — если TM id уже подтверждён в `data/penalties/penalties.csv`.
- Правила отбора матча (`note`, первая часть):
  - `воротар у полі` — основная позиция GK, а в матче позиция 2–14;
  - `воротар забив` / `воротар забив (пенальті)` — вратарь с голом (позиция GK или неизвестна);
  - `захисник у нападі` — основная CB/RB/LB, в матче позиция 13 или 14;
  - `польовий у воротах` — основная CB/RB/LB, в матче позиция 1.
- В `note` дальше: тип матча (`офіційний` / `товариський` / `молодь` — по коду турнира TM), проверка личности
  (`id OK` или `id СУМНІВНИЙ: …`), счёт, клубы TM и распределение позиций за карьеру по TM.
- Проверка личности: сомнительно, если у человека ≥ 10 матчей УПЛ в пуле, а в TM матчей `UKR1` меньше 20% от этого;
  или вратарь пула в TM вратарём меньше чем в 30% матчей с известной позицией; или защитник — защитником меньше 30%.
- `competition` — код турнира TM: UKR1 УПЛ, UKR2 Первая лига, UKRP Кубок Украины, CL/CLQ/EL/ELQ — еврокубки и
  квалификации, FS — товарищеские, U17Q/U19Q/U21Q и т. п. — молодёжные.

## Оговорки

- **Позиция в матче у TM — из стартового состава/схемы, иногда грубая.** Одиночные «90 минут центрфорвардом» у защитника
  (Караваєв, Данченко, Помазан, Овсієнко-вратарь в Венгрии) могут быть ошибкой разметки — перед трофеем сверить по отчёту
  матча (`source_url`).
- **Голы вратарей без позиции.** Если `positionId` пуст, а основная позиция GK, строка помечена как Goalkeeper — гол мог
  быть забит, когда человек играл в поле или это вообще ошибка TM.
- **Исправлено 01.10.2026:** Дмитро Шутков (было TM 619988 — Dobromir Mitov → **14941**) и Андрій Товт (было 89540 —
  André Carvalho → **27216**); id поправлены в `data/penalties/penalties.csv`, CSV пересобраны. У настоящего Товта —
  2 гола с пенальти в Первой лиге (23.06.2006 и 21.07.2006); у Шуткова эпизодов нет.
- **Неверные личности (строки не использовать):** TM id из `data/penalties/penalties.csv` указывают на других людей.
  Правильные id (дата рождения + матчи УПЛ сверены с пулом): Сергій Єсін 80090 (Ussoltsev) → **57873** (254 УПЛ = 254 в пуле),
  Микола Сич 400938 (Nikola Jokisic) → **966827** (45 УПЛ / 38), Олег Сизон 9770 (Libor Sionko) → **883860** (30 / 30),
  Саша Джурічич 1802 (Sascha Bäcker) → **28392** (125 / 123), Сергій Деренов 532358 (Andrey Cherenkov) → **664478**
  (8 / 8, вратарь). После правки в `penalties.csv` — перезапустить `collect.py`, их ложные строки уйдут.
- **Смена амплуа, личность верная (id `tm:` из пула):** Максим Войтиховський (97 матчей нападающим), Юрій Бушман,

  не пасхалка.
- 1990-е в TM неполные: эпизоды тех лет недосчитаны; 595 `w:`-людей без TM id не проверены вовсе.
- Молодёжные и товарищеские матчи остались в `candidates.csv` (помечены в `note`), но в свод «официальных» не входят.
