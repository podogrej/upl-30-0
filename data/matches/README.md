# Матчи УПЛ 1992–2026/27 (даты, счёт)
Источник: Transfermarkt (gesamtspielplan, сезоны 1991–2026; `collect_tm.py` -> `raw_tm.csv` -> `build_matches.py` -> `upl_matches.csv`); весна 1992 — группы с TM + финал и матч за 3-е место с uk.wikipedia. Название клуба -> slug пула: `club_names_map.csv` (единственный новый slug: `ska-odesa`, только весна 1992).
Покрытие: 8003 матча, 1992 (весна, 182) и 1992/93–2025/26 — все туры с датами; 2026/27 — 239 из 240 матчей (53 сыграно, 186 запланировано; 2 без даты).
Проверка: `check_wiki.py` сверяет голы клубов с таблицами uk.wikipedia (совпало в 20 сезонах); расхождения — технические результаты (пометки в `source`: `forfeit?`, `score_not_in_wiki_table`, `annulled_club_withdrew`; список в `suspect_scores.csv`).
Пробелы: 2017/18–2019/20 только первый этап (22 тура), второго этапа (по 60 матчей) нет; 2014/15 нет Чорноморець–Металіст, 2021/22 нет Інгулець–Рух, 2026/27 нет Чорноморець–Колос; 2016/17 в wiki только 22 тура (в TM все 32).
standings.csv местами расходится с обоими источниками (±1 гол), поэтому эталоном взяты wiki-таблицы. Даты: если у матча в TM нет даты, берётся предыдущая; перенесённые матчи имеют фактическую дату.
Матчи 1992 весна: раунды `1..N` — групповой этап (две группы по 10), `final`, `3rd place`.
