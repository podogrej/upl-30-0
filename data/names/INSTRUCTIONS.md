# Завдання: українські імена гравців УПЛ для карток гри

Ти отримуєш TSV-файл із гравцями Української Прем'єр-ліги (1992–2026). Для кожного рядка потрібно дати **відображуване ім'я українською** у форматі, як на картках футбольних ігор: **«Ім'я Прізвище»** (без по батькові), або футбольне прізвисько, якщо гравець відомий саме під ним.

Колонки вхідного файлу: `id, uk, ru, en, nationality, pos, seasons, clubs, auto_proposal`
- `uk` — ім'я з української Вікіпедії (зазвичай «Прізвище Ім'я По батькові»), може бути порожнім
- `ru` — з російської Вікіпедії («Фамилия Имя»), може бути порожнім
- `en` — з Transfermarkt (англійська транслітерація «Name Surname»), може бути порожнім
- `nationality` — громадянство (може бути порожнім), `pos` — позиція (GK/DF/MF/FW), `seasons` — сезони в УПЛ, `clubs` — клуби в УПЛ
- `auto_proposal` — автоматична пропозиція (просто переставлені слова); її треба ПЕРЕВІРИТИ і виправити, вона часто неправильна для іноземців

## Правила

1. **Формат**: `Ім'я Прізвище` українською кирилицею, без по батькові. Частки зберігаємо: «Карлос де Пена», «Ян ван дер Хейден».
2. **Бразильці та інші, відомі під футбольним іменем** — використовуй саме його, як в українській Вікіпедії / протоколах УПЛ: «Брандао», «Фернандіньйо», «Тайсон», «Марлос», «Ісмаїлі», «Жадсон», «Луїс Адріано», «Дуглас Коста», «Жуніор Мораес», «Дентіньйо», «Веллінгтон Нем», «Алан Патрік», «Тете», «Бернард», «Фред», «Віллян», «Ілсіньйо», «Матеус», «Едмар», «Марлон». Довгі повні імена («Соуза да Сільва Луіс Адріано») зводь до вживаного футбольного імені («Луїс Адріано»).

7. Одне слово (мононім) залишай одним словом («Брандао», «Марлісон», «Тайсон»).
8. Не вигадуй по батькові і не додавай зайвих слів; результат — зазвичай 2 слова (максимум 3 з часткою).
9. Якщо сумніваєшся у транслітерації прізвища, орієнтуйся на те, як його пишуть українські протоколи УПЛ (сайт УПЛ, UA-Футбол, Football24, uk.wikipedia). ## Вихід

Запиши файл у форматі CSV з роздільником `;` і заголовком, **по одному рядку на кожен id з вхідного файлу, у тому ж порядку, без пропусків і дублікатів**:

```
id;display_uk;conf
tm:345772;Брайт Енобахаре;high
```

- `conf` = `high`, якщо впевнений; `check`, якщо є сумнів (незвична транслітерація, невідомий гравець).
- Без лапок, без зайвих колонок, без коментарів. Апостроф у іменах — звичайний `'` (В'ячеслав, П'ятов, Дем'янюк).

Після запису файлу перевір: кількість рядків (без заголовка) дорівнює кількості рядків у вхідному файлі, усі id збігаються. У фінальній відповіді напиши лише: шлях до файлу, кількість рядків, кількість `check`, і 5–10 випадків, у яких ти найменше впевнений.
