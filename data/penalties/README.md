# Пенальти: кто и как бил (и отбивал)

Что это: для каждой «человеко-карточки» (id `p[5]` в `src/pool.json`) — пенальти за карьеру по данным Transfermarkt:
сколько пробил и забил (полевые), сколько встретил и отбил (вратари); отдельно — в УПЛ. Нужно для режима 5×5 и серий
пенальти (решение владельца 30.09.2026, `docs/leagues_online.md`, раздел «Пенальти»). В игре ничего не меняет.

## Файлы

| Файл | Что |
|---|---|
| `collect.py` | сборщик (идемпотентный, с кэшем, `CACHE_ONLY=1` — перестроить CSV без сети) |
| `penalties.csv` | данные с источниками, одна строка на кандидата |
| `skill.py` | модель навыка (байесовская реализация / доля отбитых) → `skill.md` |
| `skill.md` | предложение модели для владельца + топ-20 пенальтистов и топ-10 вратарей |

Запуск из корня репозитория:
```
python3 data/penalties/collect.py <папка кэша> [минут_бюджета=230]
CACHE_ONLY=1 python3 data/penalties/collect.py <папка кэша>
python3 data/penalties/skill.py --md
```
Если рядом с папкой кэша лежат кэши `../class` и `../foot` (сборщики `data/class`, `data/foot`), они используются только
на чтение: уже подтверждённые TM id и даты Wikidata — меньше запросов.

## Кандидаты и покрытие (30.09.2026, сбор ~4 ч, затем остановка по бюджету)

- Кандидаты: **2166** человек — ≥ 3 сезонов в пуле или карточка ≥ 80, плюс все вратари с ≥ 30 матчами УПЛ.
  Порядок: нападающие и атакующие полузащитники (760), вратари (184), остальные (1222).
- Данные Transfermarkt собраны у **1989 из 2166 (92%)**: атакующие 722/760, вратари 173/184, остальные 1094/1222.
  Карточка ≥ 80 — 1219 из 1281. Вратари с ≥ 30 матчами УПЛ — 133 из 137.
- Как найден TM id у `w:`-людей: Wikidata P2446 + та же дата рождения — 581; уже проверенные ссылки (`data/class`, `data/foot`,
  `data/positions`) — 172; поиск на transfermarkt.com + дата рождения — 149. `tm:`-id — напрямую.
- Не найдено 177: все с `w:`-id, почти все из 1990-х (146 из них впервые в пуле в 1990-х); 7 — с неизвестной датой в id (`-00`).
  Самые высокие: Флорін Чернат, Паріт Джіхані, Сергій Шматоваленко, Юрій Букель (по 85). У восьми из них TM id вручную
  подобран в `data/class/fill_manual.py` — сюда он пока не подтянут (можно добавить при реализации 5×5).
- Кто хоть раз бил пенальти: 1060 человек; вратарей с пенальти: 173. Всего в данных 7768 ударов полевых (6237 голов, 80%),
  вратари встретили 4137 пенальти и отбили 734 (17.7%). В УПЛ — 2218 ударов, 1751 гол.
- **FIFA / EA FC (sofifa.com)**: закрыт Cloudflare («Attention Required», 403) уже на первый запрос — пропущено, `fifa_pen` пустая.

## Колонки `penalties.csv`

Основные (как в задаче): `person_id, name, pen_taken, pen_scored, gk_faced, gk_saved, fifa_pen, source, url, checked, note`.
- `pen_taken / pen_scored` — пенальти в игре за всю карьеру в базе TM (все клубы, сборные, кубки); `gk_faced / gk_saved` — у вратарей
  (у полевых почти всегда 0).
- `url` — профиль TM и адрес API, откуда посчитано; `note` — как найден TM id и оговорки.

Дополнительные: `upl_taken, upl_scored, upl_gk_faced, upl_gk_saved` — то же только в УПЛ (`UKR1` в TM);
`pen_saved_by_gk` — сколько ударов игрока отбил вратарь (остальные незабитые — мимо/штанга); `gk_conceded` — пропущено с пенальти;
`games_tm, games_tracked, tracked_seasons` — сколько матчей игрока в базе TM и за какие сезоны; `tm_id`;
из пула: `mainpos, line, max_rating, seasons, upl_apps_pool, upl_goals_pool`.

## Источник

`tmapi.transfermarkt.technology/player/<id>/performance-game` — внутренний API сайта Transfermarkt (тот же, что в `data/class`),
не закрыт «Human Verification», пауза 1,5 с. В каждом матче: `penaltyShooter{Attempts,GoalsScored,Saves,Misses}` и
`penaltyGoalkeeper{Attempts,GoalsConceded,Saves,Misses}`. Сырые ответы (2–3 МБ на человека) не хранятся — в кэше только
суммы по турнирам (`pen_perf.json`). Поиск на www.transfermarkt.com — пауза ≥ 6 с, при блокировке 90 с.

## Оговорки по качеству

- **Только пенальти в игре.** Послематчевые серии в этих полях TM не считаются.
- **1990-е и 2000-е неполные.** У 33 человек в TM меньше половины их матчей УПЛ из пула (помечено в `note`). И даже где матчи есть,
  пенальти в УПЛ ~1995–2008 записаны реже: у вратарей, пришедших в пул в 1995–2009, 0.04–0.09 пенальти на матч УПЛ,
  у пришедших после 2010 — 0.14–0.17. Значит, у ветеранов число ударов занижено; модель при малом числе ударов
  стягивает к априори, так что это не искажает, а только ослабляет данные.
- **Нестыковки TM.** У 29 человек «Attempts» меньше, чем «забил + отбили» (или «пропустил + отбил» у вратаря) —
  взята сумма, помечено в `note`.
- `Misses` в TM — все незабитые (отбитые + мимо). Вратарю засчитываются только отбитые.
- Идентичность: для `w:`-id TM-профиль принят, только если дата рождения совпала с нашей и фамилия латиницей похожа ≥ 0.7.
