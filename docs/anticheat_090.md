# Античит, серия 0.90 (план 12.10.2026)

Сервер начинает сам выдавать колесо обычной игры и считать сезон в момент «Грати сезон», поэтому «любые 11» и перебор seed перестают давать проверенный сезон. «Виклик другу» и трофеи берутся только из проверенного сезона. Защита сайта от вставки чужого кода (CSP) включается сначала в режиме отчётов. Всё делится на 0.90 → 0.90.3 по правилу ≤400 строк; решения владельца — в BACKLOG («делай по рекомендациям», 12.10).

**Итог (13.10):** по решению владельца 0.90.1–0.90.3 сделаны одной версией 0.90.1 (CHANGELOG). Отличия от плана ниже: окно колеса `W` — по формату и эпохе (`api/_draft.js` `WIN`, замер `tools/wheel_window.js`: классика 17, 90-ті 43, 2000-ні 22, 2010-ті/2020-ті 12, «Один клуб» до 57); трофеи сервер пишет сам, а не только проверяет; чистка зёрен не менялась (нужно подтверждение владельца); CSP не переведён в боевой режим — сбор отчётов не работал до 0.90.1.

Ограничение: функций Vercel 12 из 12 — новых маршрутов нет, всё через `/api/seed`, `/api/save`, `/api/verify`, `/api/err` и модули `api/_*.js`. Замер: `E.run` ~9 мс на сезон, `wheelSeq` ~1,3 мс, загрузка движка ~70 мс.

## 0.90.1 — серверное колесо (К-1, К-2)
- `/api/seed {draft:'start', …}` → `{seed_id, ws}`; строка `season_seeds` с `wheel_seed`, `kind='draft'`, `era`, `club`, `rerolls`, `fl_id`, `chal_id`. Правила лиги с друзьями и вызова — из базы, не от браузера.
- `/api/seed {draft:'lock', seed_id, xi}` на «Грати сезон»: `checkDraftXi` (новый `api/_draft.js` по образцу `_vd.js`: клуб-сезоны из первых `W` позиций колеса, не больше `R` вне колеса), сервер считает сезон (`res`, `locked_at`), отдаёт `{seed_id, seed, res}`; повтор с тем же составом — тот же seed, другой — 409.
- `W` замерить ботом `tools/sim30.js` (максимум честного индекса + 2, старт 24). `R`: «Звичайний» 2, «Складний» 0, лиги с друзьями — из правил.
- Колесо в браузере — `wheelFor(ws, …)`, общий код с `lib/engine.js`; для `classic/all` побитово равен старому `wheelSeq` (тест `wheel_parity.js`).
- Без сети за 6 с — локальное колесо, сезон «без перевірки» (строка под результатом — через impeccable).
- Старые вкладки: seed `kind='legacy'`, verify `null`, попытки лиг чатов не сгорают; льготных часов нет.
- Дневной лимит драфтов на игрока — 60 (сверить с базой), сверх — сезон не проверяется.
- Скрытые форматы (вибір сезону, дерби, антисезон, легенды, хардкор) — сервер отказывает в старте драфта, сезон не проверяется.
- Лиги с друзьями: попытка пишется в `fl_entries` на lock из `res` (брошенная тоже), `fl_record_seed`.
- Чистка зёрен: не трогать строки с `locked_at`.
- Риски: ложные отказы честным игрокам (окно `W`, расхождение пула, ошибка `wheelFor`) — тест «5000 драфтов бота проходят проверку»; «Грати сезон» медленнее (до 1–1,5 с на холодном старте).
