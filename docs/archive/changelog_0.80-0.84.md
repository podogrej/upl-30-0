## 0.84 — 10.10.2026

«Плавний рух»: анимации из прототипа v2 (пункты 1–12, кроме 8) и трофеи итога сезона из прототипа v1 (п. 5); «Вибір сезону» спрятан. Симуляция не менялась (`lib/engine.js` отличается только `VERSION`, determinism 10/10). **SQL нет.**

**Игра**
- **Токены движения:** `--spring` — критически затухающая, без перелёта (экраны, кнопки, переключатели, бегунки); прежняя пружина с перелётом 8 % — `--spring-pop`, только у «приземлений» (слот, чип вердикта, рейтинг, точка в плашке, кубок, жетон трофея). Новые `--dur-0` (100 мс, нажатие) и `--dur-out` (160 мс, выходы). В JS — один `MOTION` (читает токены из CSS) и одна `LESS_MOTION()` вместо четырёх проверок (`vtOK`, `draftWave`, `sheetMotion`); литералы длительностей в `flipRows`, `odoSet`, `slide`, аккордеоне, `countUp`, шторках и перелёте игрока — через `MOTION`. `window.__fastMotion` (тесты) — 1 мс.
- **«Виклик дня», блок условия** (`vdBrief`): разметка строится один раз на попытку, дальше обновляется на месте — цифра прокручивается (`odoSet`) с коротким увеличением (`bump`), сегмент заполняется сдвигом (420 мс), строка «Зараховано» растёт по высоте от текущего значения (`smoothHeight`, 360 мс, без скачка блока), новое имя проявляется. Условие выполнено: зелёный слой проявляется прозрачностью, галочка раздвигает место и появляется с поштовхом, блок «садится» 0,98 → 1, `haptic('success')`. Плашка `#vdBar` — тоже на месте.
- **Драфт:** счётчик «n/11» и плашка — лента цифр + увеличение (только при +1; «Спочатку» и открытие — сразу); полоса — `translateX` внутри обрезанной дорожки; потраченная перекрутка гаснет (scale .6, opacity .35), точки строятся один раз; точка в плашке заполняется с поштовхом.
- **Целевой слот:** статичное кольцо + псевдоэлемент-пульс дважды (1200 мс), второй слот на 150 мс позже; появление 0,92 → 1. Бесконечный `box-shadow`-пульс убран; «Зменшити рух» — только кольцо.
- **Тост:** выход тем же путём вниз (160 мс), замена — старый уходит за 120 мс, новый входит сразу; с «Зменшити рух» — только прозрачность.
- **Вкладки и эпохи:** бегунок под вкладками (`#tabs`, `#tbTabs`) едет `translate+scaleX`, плашка эпох открывается `clip-path` (`segInd`, пересчёт по `ResizeObserver`); содержимое вкладки проявляется за 120 мс.
- **Колесо:** вместо `filter: blur` на ленте — статичная маска по краям окна; время ленты прежнее.
- **Прогноз:** полосы растут один раз (500 мс, шаг 40 мс), при перестановках — сразу; полоса подсчёта xP — `transform`.
- **Тема:** перекрёстное затухание через View Transitions (240 мс); без них или с «Зменшити рух» — мгновенно.
- **Отклик на нажатие:** пилюли и переключатель темы — как кнопки (0,97 + яркость); текстовые ссылки (`.links0`, подвал, `a.plink`) — только притемнение; вопросы FAQ — только фон.
