## Старые «ліги» и 5×5
- `leagues*` + `league.js` + бот + cron — **живые** лиги Telegram-групп для виклика дня. С новыми лигами не совпадают; имена таблиц заняты → новым нужен другой префикс.

## Сверка схемы основной базы (sql/check_schema.sql, 30.09)
Основная база совпадает с A+B почти полностью: все 16 функций — те же тела (md5), права на функции, политики seasons/trophies/challenges/f5/leagues/players/user_state, триггеры, таблицы (кроме одной) — одинаковые. Отличия:
- **daily_results** в основной базе строже, чем в файлах: `w,d,l,pts,place,gf,ga` — smallint NOT NULL, `formation`, `xi` NOT NULL, проверки `w+d+l=30`, `pts=3w+d`, диапазоны, `nickname` 2–24 (char_length). В файлах (A) — integer без проверок. Сервер, который пишет результат дня, обязан заполнять все NOT NULL поля.
- **Имена политик daily_results для anon другие:** в основной базе `"insert today"` (check как у `"daily insert auth"`) и `"read all"`; в файлах — `"daily insert"` и `"daily read"`. Любой `drop policy` должен называть обе версии имён.
- Индекс `daily_results_day_pts_idx` (основная) вместо `daily_top_idx` (файлы) — то же назначение.
- `rls_auto_enable()` — служебная функция Supabase, pgcrypto в схеме `extensions` (в тестовой заглушке — в public). Не наше.
Итог: схема прода известна, расхождение одно (daily_results), для 0.53 это учитываем.
