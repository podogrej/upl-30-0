## Старые «ліги» и 5×5
- `leagues*` + `league.js` + бот + cron — **живые** лиги Telegram-групп для виклика дня. С новыми лигами не совпадают; имена таблиц заняты → новым нужен другой префикс.
- `f5_*` + `five.js` — **живой** 5×5 по ссылке `?r=`, всё в браузере, запись открыта всем. Как основа для лиги 5×5 не годится: нужны новые таблицы с записью через сервер и движок 5×5 в `lib/engine.js`.
