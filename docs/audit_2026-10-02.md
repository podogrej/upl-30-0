## Старые вкладки (п. 7)
- `PREV_VERSIONS = ['0.65','0.64']` (`verify.js:35`) после изменения симуляции в 0.66 ничего не принимает, только открывает P1-2. Правило: при каждом изменении симуляции — `[]`; при выпуске без изменения симуляции — `[предыдущая]`. Для 0.67 (баланс v3) — `[]`.
- Нет подсказки «вийшла нова версія». Вкладка 0.66 после выхода 0.67 сыграет драфт дня, сервер ответит `null`, результат **не попадёт в таблицу дня**, и игрок не узнает почему. Предложение: `/api/seed` отдаёт `engine.VERSION`; если он не совпадает с `VERSION` страницы, перед драфтом дня показать «Оновити гру» (`location.reload()`). Сим. ✓
- `VERSION` берётся регэкспом из текста подвала (`1525`, В14 из аудита 30.09). Если поменять текст подвала, получится `'?'`, и все сезоны станут «не перевірено». Подставлять при сборке из `lib/engine.js` (`build.py`).
- Вкладки до 0.53 пишут напрямую: после `v054` их запись молча падает. Это ожидаемо и описано в DECISIONS п. 16.
