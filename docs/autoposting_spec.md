# Автопостинг «Дім ностальгії» — Telegram + Threads

Статус: спека согласована с владельцем 07.10.2026 (сессия claude-setup, прожарка планом). В работу — пакетом по правилам CLAUDE.md («Как берём работу»).

## Цель

Посты о ностальгии по УПЛ выходят в Telegram-канал @upl_nostalgia и в Threads «Дім ностальгії» без участия владельца. Владелец только подтверждает посты первые 3 недели.

## Что уже есть (не ломать)

- Очередь `channel_posts` и `api/_channel.js`: draft → pending_approval (превью владельцу в @upl30_bot с «Опублікувати» / «Відхилити») → published | rejected | failed.
- Авточерновики: анонс дня (вечером накануне) и итоги недели (понедельник). Остаются как есть.
- Запуск очереди: GitHub Actions каждые ~10 мин + ежедневный `api/cron`.

## Что добавить

### 1. Площадка Threads
- Официальный Threads API Meta (не посредники). Аккаунт Threads «Дім ностальгії» на отдельном Instagram бренда (не личном).
- Секреты (`THREADS_USER_ID`, `THREADS_TOKEN` и т. п.) — только в Vercel, их вписывает владелец. Для владельца — пошаговая инструкция со скриншотами: создание приложения в Meta for Developers, use case Threads, получение долгоживущего токена.
- Токен живёт 60 дней: автоматическое продление по расписанию; если продление упало — сообщение владельцу в бот заранее.
- Один пост в очереди = одна площадка. Схема — только добавлением (DECISIONS п. 13), например колонка `platform` ('telegram' | 'threads', по умолчанию 'telegram') или отдельная связанная таблица — на усмотрение, с обоснованием в DECISIONS.
- Лимит Threads — 500 символов; проверка длины как `checkPost` для Telegram.

### 2. Автоматическое написание постов (раз в неделю)
- Задача по расписанию в Claude (scheduled task), воскресенье. Пишет пачку на неделю и кладёт черновики в `channel_posts` с `publish_at` (через Supabase-коннектор или защищённый эндпоинт).
- Одна тема → два текста: Telegram (полный, с фото) и Threads (короткий, крючок в первой строке).
- Рубрики: «Цей день в УПЛ», забуті герої, легендарні матчі, «Вгадай гравця за фото», новини гри.
- Частота: Telegram — ностальгия 4 раза в неделю (+ существующие анонсы игры); Threads — 1 раз в день.
- Время (Киев): Telegram 10:00, Threads 19:00.
- Ссылка на «Головоломку дня» — примерно в каждом третьем посте.
- Язык: украинский, на «ти», от имени бренда, живо, без канцелярита; каждый текст проходит скилл `unslop`. Без номеров версий и служебных пометок.
- Промпт задачи и правила рубрик хранить в репозитории (например, `docs/autoposting_prompt.md`), чтобы задача и сессии брали одно и то же.

### 3. Фото
- Только свободные лицензии (Wikimedia Commons и подобные) с подписью автора и лицензии в посте; обработка под аналоговую плёнку (визуальное направление канала).
- Нет подходящего свободного фото — пост с карточкой-цитатой в стиле канала, без фото. Сгенерированные ИИ «реальные люди» — нельзя.
- Перед генерацией карточек — собрать референсы стиля канала, потом сверить результат с ними.

### 4. Подтверждение владельцем
- Недели 1–3: каждый пост — превью в бот с кнопкой, как сейчас (для Threads — тот же поток, с пометкой площадки).
- После 3 недель (включает владелец одной настройкой): автомат. За час до выхода — сообщение «Скасувати»; молчание = публикация.

### 5. Сбои
- Любая ошибка публикации (токен, отказ Telegram/Threads, нет фото) — сразу сообщение владельцу в бот: какой пост и причина. Пост остаётся в очереди на повтор, ничего не теряется молча.

## Не в первой версии
- Instagram-постинг (только профиль-вход в Threads со ссылкой на сайт).
- Автоответы на комментарии в Threads.
- Еженедельная сводка просмотров по рубрикам (вторая версия: по ней подстраивать следующую пачку).

## Порядок внедрения
1. Владелец: Instagram + Threads «Дім ностальгії», приложение Meta, токен в Vercel (по инструкции).
2. Threads как площадка в очереди + продление токена + уведомления о сбоях.
3. Еженедельная задача-генератор + правила рубрик + фото.
4. 3 недели с подтверждением → переключение на автомат.
