# Живая проверка лиг 11×11 и 5×5 (перед 0.69)

Зачем: автотесты лиг проходят, но на основной базе было лишь 1 лига 11×11 с одним участником и ни одной 5×5 — сценарий «несколько живых людей» не проверялся.

Кто: владелец, Витя, Игорь (3 телефона/iPad, у каждого вход через Google или Telegram). Время: ~15 минут.

## 11×11
1. Владелец: главная → «Ліга з друзями» → «Створити» → 11×11, 1 день → «Створити» → «Поділитися посиланням» в общий чат.
2. Витя и Игорь: открыть ссылку → войти → «Приєднатися». ✅ У всех в лиге 3 участника.
3. Каждый: «Зіграти спробу» → сезон → «До ліги». ✅ В таблице лиги 3 результата, имена правильные.
4. Скрин таблицы лиги у каждого.

## 5×5
1. Владелец: «Ліга з друзями» → «Створити» → 5×5 → ссылка в чат.
2. Витя и Игорь входят по ссылке. Владелец: «Почати» (нужно ≥2 состава).
3. Каждый собирает пятёрку → ждём остальных → турнир → финал и серия пенальти.
4. ✅ У всех одинаковый итог, трофеи 5×5 выданы. Скрин итога у каждого.

## Если что-то не так
Скрин + время (по Киеву) — по времени найду запрос в логах сервера.
