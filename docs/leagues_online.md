# Онлайн-лиги с друзьями — ТЗ, черновик 1 (30.09.2026)

Цель: 0.69, показать друзьям. Два формата: **11×11** и **5×5** (решение владельца).

## Референс: 38-0 «Leagues» (скриншоты владельца, 30.09.2026)
**Список лиг:** «Create a league» (главная кнопка), под ней «Отримав посилання? Просто відкрий його». «Твої ліги»: Грають / Завершені; строка лиги — название, бейдж категории, «ліга podogrej · Normal · …», статус («Нова через 3 год», «Закрита»), место «#1 з 11», кнопки «перейменувати» и «×». Ниже 3 карточки «як це працює» (правила → кожен збирає склад → найкращий виграє).
**Создание («Set the rules»):** одни настройки для всех, отличается только состав; схему выбирает каждый сам.
- Тип: **One-off** (одна таблица, лучший результат к дедлайну) · **Ongoing** (новый вызов каждый день) · **Last One Standing** (раунды по времени, худшие вылетают, пока не останется один).
- Блок «Як працює ліга» из 5 шагов: правила → сыграй сам первым → отправь ссылку → друзья играют по тем же правилам → больше очков к дедлайну — победа.
- Имя игрока (из аккаунта), название лиги — 3 смешных варианта + «Перемішати».
- Категория (Mates / Work / Family / …), рейтинги (сезон / пик), сложность (3 / 1 / 0 перебросов), рейтинги видны или нет, эпоха, лимит игроков (2 / 10 / 50 / без ліміту), кто может войти (только с аккаунтом — рекомендовано / все), зачёт (**последний** забег или **лучший**; фиксируется при создании), срок (15 мин … 1 тиждень / без дедлайну).
- Кнопка «Створити лігу й грати» → ссылка для друзей, потом свой сезон.
Прямых матчей между участниками нет: каждый играет свой сезон против одних и тех же соперников, сравниваются очки.

## Решения владельца (30.09.2026, ответы на вопросы)
**Общее**
- Вход только с аккаунтом. Лиги — на главной; в шапке кнопка с понятным названием («Мультиплеєр» / «З друзями» — выбрать).
- Режим лиг — класика. Рейтинги видны / «на пам'ять» — выбор создателя.
- Эпохи нужны — и в лигах, и в обычных режимах.
- Рейтинг **сезона или пик** — нужен выбор «пікова версія гравця» (после переработки рейтингов, см. BACKLOG).
- Названия лиг — ~30 смешных вариантов на украинском, «Перемішати».

**11×11 — ліга на кілька днів**
- Лига идёт N дней (срок выбирает создатель). **Каждый день — тур**: у каждого до 3 попыток; в зачёт тура — последняя или лучшая (выбор создателя).
- Очки тура — выбор создателя:
  - **сума** — очки сезона суммируются;
  - **за місце** — из сыгравших в этот день K человек: 1-й получает K, последний 1 (9 сыграли → 9…1; 8 → 8…1). Не сыгравший — 0.
- Итог — сумма по турам к дедлайну.

**5×5 — справжні матчі між складами**
- Матчи составов друг против друга (новая симуляция «склад проти складу»).
- Групповой этап **кожен з кожним**; дальше:
  - 3–7 игроков → 2 лучших в **фінал**;
  - 8+ → 4 лучших: **півфінали й фінал**.
- В плей-офф ничья → **серія пенальті**.
- Матч подробный: автор каждого гола с обеих сторон, минуты; эпизоды «суддя призначив пенальті» → удар; **VAR**: суддя пішов до монітора → пенальті підтверджено / рішення скасовано.

## Решения владельца, раунд 2 (30.09.2026)
- Перебросы: создатель выбирает для всех — 3 / 1 / 0.
- Лимит: 5×5 — максимум 10 человек; 11×11 — без ограничения.
- 5×5: все собирают составы до дедлайна → сервер разыгрывает весь турнир → каждый смотрит свои матчи (голы, пенальти, VAR). Подробный сценарий — ниже, на утверждение.
- 11×11: колесо у каждого своё, случайное (одинаковые клубы для всех — не нужно).
- Рейтинги: **вариант Б** — усложнить формулу, добавить класс игрока (сборная, еврокубки, трансферы, награды). См. BACKLOG.
- Кнопка в шапке: **«Грати з друзями»**.
- Трофеи: **рідкісні** и **секретні** — две разные сущности, не пересекаются.

## 5×5: сценарий по шагам (на утверждение)
1. **Создание.** Название, перебросы (3/1/0), рейтинги видны / «на пам'ять», эпоха, срок набора (1 год / 3 год / 24 год…). Создатель сразу собирает свою пятёрку.
2. **Ссылка** → друзья входят (только с аккаунтом), до 10 человек. Видно, кто уже собрал состав (без самих составов — чтобы не подглядывали).
3. **Сбор пятёрки:** воротарь + 4 польових через колесо, у каждого своё; схема на выбор (2-1-1, 1-2-1…). Отправил — изменить нельзя.
4. **Дедлайн** (или все собрали и создатель нажал «Почати зараз»). Не успевшие не участвуют. Меньше 2 составов — лига отменяется.
5. **Сервер разыгрывает всё сразу**, зерно фиксируется → результат одинаковый у всех и проверяемый:
   - група: кожен з кожним, 1 матч; 3 очки за перемогу, 1 за нічию; равенство — різниця м'ячів → забиті → очна зустріч;
   - **2 учасники (дуель, власник 30.09)** → без групи: один матч, нічия → серія пенальті; опція створювача «до двох перемог» (серія до 3 матчів);
   - 3–7 учасників → фінал (1-й і 2-й); 8–10 → півфінали (1–4, 2–3) і фінал;
   - плей-офф: нічия → серія пенальті (5 ударів, далі до першого промаху).
6. **Всем приходит** (сайт + Telegram-бот): «Турнір зіграно». Экран лиги: таблица группы, сетка, чемпион.
7. **Матч** открывается кнопкой: счёт, лента эпизодов по минутам с обеих сторон — голы (автор, асист), «Суддя призначив пенальті» → удар (забив / сейв / мимо), «VAR: суддя йде до монітора» → «пенальті підтверджено» / «рішення скасовано». Можно смотреть «наживо» (эпизоды появляются по одному, ~30 сек на матч) или сразу итог.
8. **Итоги:** трофеи за лигу (переможець, без поразок, король пенальті…), кнопка «Реванш» — та же компания, новая лига.
Основа: в коде уже есть прототип 5×5 (матч с лентой событий, `f5*`) — расширяем, а не пишем с нуля.

## 11×11: сценарий по шагам (на утверждение)
1. **Создание.** «Грати з друзями» → «Створити лігу» → формат **11×11**. Создатель выбирает: название (30 вариантов + «Перемішати»), перебросы 3/1/0, рейтинги видны / «на пам'ять», эпоха, **тривалість** (1 / 3 / 7 днів), **попыток в день** (1 / 3), в зачёт тура **найкраща / остання** попытка, **очки**: сума / за місце. Кнопка «Створити й грати» → ссылка + сразу своя первая попытка.
2. **Ссылка** → друзья входят (с аккаунтом), лимита нет. Можно войти в любой день — пропущенные туры = 0.
3. **Тур = календарный день по Києву (00:00–23:59).** Колесо у каждого своё. Попытка = обычный сезон классики: драфт → сезон → очки. Сервер проверяет сезон тем же движком (как сейчас).
4. **Зачёт тура.** После каждой попытки таблица дня обновляется сразу. Если «за місце» — места и очки тура пересчитываются, пока день не закончился (кто-то сыграл позже — все сдвигаются). В 00:00 тур закрывается.
5. **Общая таблица** = сумма очков за туры. При равенстве — больше побед в турах → лучший одиночный сезон.
6. **Напоминание** (Telegram-бот, по желанию): вечером, если сегодня ещё не играл: «Тур закінчується о 00:00, у тебе 3 спроби».
7. **Финал лиги.** В последний день в 00:00 — итог, чемпион, трофеи за лигу (переможець ліги, виграв усі тури, камбек з останнього місця…), «Реванш».
