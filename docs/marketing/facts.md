# Паспорт игры 30-0 УПЛ для маркетинга

Что в игре есть на сегодня: только эти цифры и названия можно писать в постах. Файл обновляет разработчик при каждом выпуске, дата ниже. Если нужного факта здесь нет — не придумывай, запроси через владельца.

**Обновлено:** 20.10.2026, версия 0.92.

## Суть одной фразой
Тебе выпадает клуб и сезон УПЛ, ты берёшь из этого состава одного игрока, так 11 раз; потом игра симулирует сезон из 30 матчей. Цель — 30 побед из 30 («30-0»). Слово «колесо» в маркетинге не используем.

Текст превью сайта (как его показывают Telegram, Threads и поисковики), с 21.10: заголовок «30-0 УПЛ — чи пройде твоя збірна УПЛ усіх часів сезон без поразок?», описание «Збери найкращу команду в історії УПЛ і перевір, чи пройде вона сезон без жодної поразки. Безкоштовно, без реєстрації, у браузері й у Telegram.» Картинка — `og.jpg` (поле, «Збери збірну УПЛ усіх часів»).

## Цифры
- **35 сезонов** УПЛ: с 1992 по идущий 2026/27 (текущий сезон обновляется по ходу).
- **540 клуб-сезонов**, **4 601 футболист**.
- **153 трофея**, из них **68 секретных** (с пасхалками).
- Каждый результат проверяет сервер: в таблицах только честные сезоны.
- Бесплатно, без рекламы, в браузере (upl30.com.ua) и в Telegram (бот @upl30_bot, мини-приложение). Неофициальный фан-проект.

## Режимы, которые видит игрок (названия — как в игре)
- **«Грати»** — основной драфт. Уровни: «Звичайний» (рейтинги скрыты до сезона, 2 перекручування), «Складний», «Хардкор», «Тренування». Можно ограничить эпоху: 90-ті, 2000-ні, 2010-ті, 2020-ті.
- **«Виклик дня»** — каждый день новое задание (например, «1 гравець Оболоні і 1 гравець Вереса») и бонус за знание футбола. Счёт N из 11, медали за 4 / 6 / 9 / 11. 3 спроби на день. Пропущенный день можно сыграть из архива.
- **«Вибір сезону»** — выпадает клуб, сезон выбираешь сам из трёх.
- **«Один клуб»** — лучший XI одного клуба за всю его историю в УПЛ.
- **«Ліга з друзями»** — своя лига по ссылке, общие правила и таблица.
- **Ліга чату** в Telegram — бот ведёт таблицу в групповом чате (`/league`).

## Поделиться результатом (с 0.92)
- Под результатом сезона одна кнопка **«Поділитися»**. В Telegram она отправляет картинку-карточку через @upl30_bot с подписью «⚽ 30-0 УПЛ…» (результат, бомбардир, серия, новые трофеи) и кнопкой «Зібрати свою 11-ку»; в браузере открывает системное меню с картинкой; иначе копирует текст со ссылкой.
- Ссылка ведёт на результат: `upl30.com.ua/r/<номер>` с метками `utm_source=share&utm_medium=telegram|web|copy&utm_campaign=result`. Превью ссылки — картинка именно этого сезона (после первого шеринга), иначе общая.
- Друг по ссылке видит результат автора (звание, счёт, состав) и одну кнопку **«Зібрати свій склад»** — сразу драфт, без регистрации.
- **«Виклик дня»**: по ссылке видно медаль, «N з 11» и номер вызова (№1 — 09.10.2026). Состав автора в день вызова скрыт («Склад відкриється завтра»), открывается на следующий день. На карточке вызова фамилий нет.
- Кнопки «Кинути виклик другу» больше нет; разосланные раньше ссылки-вызовы работают.
- Шеринги считаются в статистике трафика (событие `share`).

## Чего в игре нет (не писать)
- «Драфт дня» — больше нет, его заменил «Виклик дня».
- «Проверить прогноз» — такой функции нет.
- Цифры «34 сезони», «524 клуб-сезони», «4 547 футболістів», «119 трофеїв» — устарели.
- Скрытые режимы («Класичне дербі», «Антисезон», «Ліга легенд») в постах не упоминать, пока владелец не скажет иное.
