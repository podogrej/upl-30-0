# Мемы для названий трофеев (исследование 10.10.2026)

Три проверки по источникам: украинский футбол (74 пункта, `football.md`), украинский интернет 2010–2026 (56, `internet.md`), поп-культура (53, `popculture.md`). Для лёгкой футбольной игры годятся около 70 из 183; военные, сакральные, политические и русскоязычные по происхождению мемы помечены в файлах (⛔ / «избегать») и в игру не идут. Ниже — короткий список лучших (узнаваемость высокая, риск низкий) с идеей трофея и пометкой, можно ли посчитать условие из данных игры.

**Что игра умеет считать.** У сезона есть итог (место, очки, голы), лог 30 матчей (счёт, результат) и статистика игроков (голы, асисты, форма, оценка). **Минуты голов — декоративные** (выдумываются для показа), поэтому условия «гол на 90+», «отыгрались с 0:2», «вели 2:0 и не выиграли» честно посчитать нельзя.
