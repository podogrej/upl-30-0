# Макети в кольорах УПЛ поверх 0.63

Справжня гра 0.63 з усіма правками власника 01.10 (головна, режими, колесо, підсумки) — змінено лише палітру (`themes.js`, токени з `../README.md`).
Огляд — **`compare.png`** (A і B × 4 екрани: головна, «Вільна гра», колесо, підсумки). Окремо — `<A|B>_<екран>.png`.
Перезняти (з кореня): `node docs/mockups/design_upl/v63/shoot.js`.

- **A · УПЛ класика (темна)** — синій фон УПЛ, градієнт UPL.TV на головних кнопках, лого й очках, синій газон.
- **B · УПЛ світла** — та сама айдентика на світлому фоні, світлий газон «папір».

**Рішення власника 01.10:** «кольори УПЛ» — це лише A (темна, темно-синій) + B (світла) з рожевими акцентами й градієнтом UPL.TV; C і D прибрано. Власник подивиться макети ближче до 0.65; газон — ще вирішити.
