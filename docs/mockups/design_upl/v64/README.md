# Макети палітр 0.64 (правки власника 01.10)

Справжня гра 0.64, темна тема (темно-синій УПЛ). Змінено лише акценти й деталі — `themes.js`, `shoot.js`.
Огляд — **`compare.png`** (4 палітри × головна, підсумки, трофеї); значок «Кукуріку» — **`rooster_preview.png`** (силует півня, `rooster.svg`).
Перезняти з кореня: `node docs/mockups/design_upl/v64/shoot.js`, `node docs/mockups/design_upl/v64/rooster_preview.js`.

1. **Корал і мед** — теплий кораловий + медовий (інший відтінок «оранжевого»).
2. **Малина й бузок** — малиновий + світлий бузковий.
3. **Індиго й фуксія** — синьо-фіолетовий + фуксія.
4. **Золото** — золотий + бурштиновий, темний текст на кнопках («кубок»).

В усіх варіантах: градієнт — лише на широких головних кнопках («Грати», «Новий драфт») і лого; вузькі кнопки — суцільний колір;
трофеї — шестикутник з градієнтом палітри, заокруглені картки з ледь помітним відтінком; xG / xGA / везіння — плитками з іконками одразу;
рядка «Ліга легенд · схема · режим · голи» на підсумках немає.
