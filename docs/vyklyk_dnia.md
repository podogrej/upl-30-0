# «Виклик дня» и лиги чатов на обычной игре: план (08.10.2026)

Суть. «Драфт дня» (общее колесо на день) уходит совсем, на его месте на главной — «Виклик дня»: условие на состав, 5 попыток, лучшая засчитывается, счёт N/11 и медаль, без соревнования. Лиги чатов считаются по обычной игре «Грати»: каждый день засчитываются первые 3 проверенных сезона игрока, в лигу идёт лучший. Таблицы уходят с главной на экран «Таблиці».

Правила вызова — в BACKLOG («Завдання дня», решения владельца 07–08.10); здесь только устройство.

## 0.79 — лиги чатов на «Грати», экран «Таблиці»

- **Какие сезоны идут в лигу**: «Грати» (классика, обычная сложность, все сезоны), проверенные сервером, первые 3 за киевский день по времени создания; в `league_results` — лучший (очки, разница мячей, забитые). Остальные режимы («Вибір сезону», «Один клуб», 5×5) в лигу не идут.
- **Сервер**: при проверке сезона (`api/verify.js`) — если это один из первых 3 подходящих сезонов дня, обновить `league_results` во всех лигах игрока, когда результат лучше. Схема базы не меняется (`seasons` уже хранит день, режим, устройство).
- **«Драфт дня» пока остаётся** до 0.80, но в лиги больше не идёт.
- **«Таблиці»**: вкладки «За весь час» и «Мої чати». С главной удаляются «Таблиця дня», плитка «Таблиця за весь час», карточка лиги чата — код удаляется, не прячется.

## 0.80 — «Виклик дня» вместо «Драфту дня»

- **Вызовы** — `lib/challenges.json` (день, заголовок-событие, повод, игрок события, обязательное условие, бонус); читают игра и сервер.
- **Игрок события** сразу стоит в составе, всегда засчитывается в бонус, в обязательное условие — нет.
- **Попытка**: собрал 11 → нет обязательного условия — попытка сгорает, сезон не играется; есть — сезон играется, счёт N/11 считает сервер.
- **База**: `challenge_results` (новый файл в `sql/`, только добавления, запись через сервер).
- **Серия и трофеи «дня»** переходят на «Виклик дня»; «Драфт дня», `daily_results` и «Таблиця дня» удаляются из кода (таблица в базе — по правилу двух шагов).
